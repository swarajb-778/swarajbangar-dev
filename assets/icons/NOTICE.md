## UI icons: Codicons

The activity bar, title bar, status bar, button and toast icons are VS Code
**Codicons**. Their SVG path data is inlined, unmodified, in
`src/lib/codicons.js` (only the glyphs this site uses).

- Package: `@vscode/codicons@0.0.45` (npm), `src/icons/` directory
- Source: https://github.com/microsoft/vscode-codicons
- Downloaded from: https://cdn.jsdelivr.net/npm/@vscode/codicons@0.0.45/src/icons/
- Icon artwork: Copyright (c) Microsoft Corporation, licensed under the
  Creative Commons Attribution 4.0 International License (CC BY 4.0),
  https://creativecommons.org/licenses/by/4.0/
- Code in that repository: MIT License, Copyright (c) Microsoft Corporation

The LinkedIn glyph is the site's own drawing; Codicons has no brand icons.
